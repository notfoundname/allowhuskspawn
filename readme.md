# AllowHuskSpawn
My first Mixin experience.

Changes Husk's spawnrules to match Zombie's.
Pair it with [Sandy Husks](https://modrinth.com/datapack/sandy-husks) datapack and you can build an authentic sand farm!

## Compatibility
Made with Paper 26.1.2 in mind, but should work with newer versions.

Needs Mixin loader, 
such as [Horizon](https://github.com/CraftCanvasMC/Horizon) or [Ignite](https://github.com/vectrix-space/ignite).
